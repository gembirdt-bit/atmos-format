# Atmos Format

Program za brisanje i formatiranje diskova — za Windows i Android.

## Windows
- Lista diskova sa nazivom, veličinom, vezom (USB, SATA, NVMe), tabelom i slovima
- Sistemski i boot disk su zaštićeni i ne mogu se izabrati
- Fajl sistem: NTFS, exFAT ili FAT32
- Particiona tabela: automatski, MBR ili GPT (GPT za diskove veće od 2 TB)
- Brzi ili pun format (pun format proverava sektore)
- Potvrda upisivanjem broja diska, napredak i dnevnik rada

## Android (USB OTG)
- Prepoznaje USB disk priključen preko OTG kabla, bez root-a
- Fajl sistem: exFAT ili FAT32
- Particiona tabela: automatski, MBR ili GPT
- Brzi ili pun format (upisuje i proverava svaki sektor)
